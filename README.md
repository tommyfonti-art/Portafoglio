# Portafoglio

Gestionale del portafoglio di Tommi: versamento mensile con calcolo delle quote, prezzo di carico e guadagno, bollo e TER, simulazione Monte Carlo, registro dei versamenti.

Sito statico su GitHub Pages, dati su Firebase (Firestore) con accesso tramite indirizzo e parola d'ordine.
La configurazione Firebase va in `firebase-config.js`; le regole del database sono in `firestore.rules`.
